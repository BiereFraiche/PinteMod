# Changelog

## v2.1.1 — stable

The current public PinteMod foundation includes the BOIII Zombies administration framework, localization, GeoIP, persistent XUID moderation, ranks, records, health diagnostics and optional Windows tools.

This version is the stable baseline used by PinteMod Control Center v2.4.5.

## Experimental additions

Community Soft Pause and selected remote-control feedback features are available for private testing. They are not part of the v2.1.1 stable guarantee.

For setup and operation, start with the [README](README.md) or [French README](README_FR.md).
