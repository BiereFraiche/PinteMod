PINTEMOD v2.1.1 — BANNISSEMENTS XUID
====================================

PRINCIPE
--------
Le système complète le vote-kick et les expulsions temporaires de manche. Un bannissement PinteMod est lié au BOIII_XUID, jamais au pseudo ni à l’adresse IP.

Le GSC vérifie les permissions et écrit une demande locale. Le PinteMod Ban Service utilise l’heure UTC Windows pour maintenir les expirations, crée un marqueur actif par XUID et conserve l’historique dans :

boiii\scriptdata\pintemod\bans\bans.json

Aucune adresse IP n’est enregistrée.

PERMISSIONS
-----------
Owner :
- peut bannir Admin, Moderator, Helper et User ;
- ne peut pas bannir un autre Owner ;
- ne peut pas se bannir lui-même.

Admin :
- peut bannir Moderator, Helper et User ;
- ne peut pas bannir Owner ou Admin ;
- ne peut pas se bannir lui-même.

Le propriétaire bootstrap suivant est toujours protégé :

BiereFraiche — BOIII_XUID 9cf34426f668fb8b

COMMANDES CONSOLE
-----------------
ezzban <Player|BOIII_XUID|ClientNumber> [durée] [raison]
ezzunban <Player|BOIII_XUID|ClientNumber>
ezzbaninfo <Player|BOIII_XUID|ClientNumber>
ezzbanlist
ezzbanstatus
ezzbantest suite

COMMANDES CHAT OWNER / ADMIN
----------------------------
.ban <Player|BOIII_XUID> [durée] [raison]
.unban <Player|BOIII_XUID>
.baninfo <Player|BOIII_XUID>
.banlist

DUREES
------
30m   30 minutes
2h    2 heures
7d    7 jours
4w    4 semaines
perm  permanent

Si aucune durée reconnue n’est fournie, le bannissement est permanent et le reste des arguments forme la raison.

EXEMPLES
--------
ezzban TestPlayer 2h insultes répétées
ezzban 1111111111111111 7d comportement toxique
ezzban 1111111111111111 perm triche
ezzunban 1111111111111111

.ban TestPlayer 30m spam
.ban 1111111111111111 perm triche
.unban 1111111111111111

FONCTIONNEMENT DU SERVICE
-------------------------
Le lanceur local démarre le Ban Service avant BOIII afin de nettoyer les expirations avant que des joueurs puissent rejoindre.

Un bannissement actif crée :

boiii\scriptdata\pintemod\bans\active\<xuid>.json

À la connexion, le GSC vérifie ce marqueur et expulse immédiatement le joueur. Lorsqu’un bannissement temporaire expire, le service supprime le marqueur selon l’heure UTC Windows.

Si le service est arrêté, un bannissement temporaire déjà expiré peut rester actif jusqu’au redémarrage du service. Pour une installation distante, toujours lancer Launch_PinteMod_Remote_Tools.bat.

LIVE CONSOLE
------------
Le filtre N affiche les événements :

PLAYER_BANNED
BANNED_PLAYER_REJECTED
PLAYER_UNBANNED
BAN_EXPIRED
BAN_REQUEST_REJECTED
BAN_SERVICE_TIMEOUT

Les bannissements et leur historique ne contiennent aucune IP.

RANKS ET RECORDS
----------------
Bannir un joueur connecté déclenche la protection UNRANKED de la partie, comme les autres commandes qui affectent directement le gameplay.

VALIDATION RECOMMANDEE
----------------------
1. ezzbantest suite doit afficher 8/8 PASS.
2. Bannir un compte de test pendant 2 minutes.
3. Vérifier PLAYER_BANNED dans la Live Console.
4. Vérifier l’expulsion immédiate.
5. Tenter une reconnexion et vérifier BANNED_PLAYER_REJECTED.
6. Attendre l’expiration et vérifier BAN_EXPIRED.
7. Vérifier que la reconnexion est ensuite autorisée.
8. Tester qu’un Admin ne peut pas bannir un Owner ou un autre Admin.
9. Tester que le XUID bootstrap Owner est protégé.
